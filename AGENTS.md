# AGENTS.md

CodeForge is a React/Vite frontend with a Node.js API and SQLite storage.

- Read README.md before changing setup or deployment.
- Preserve the existing UI and the original exercise in programming-language-toggle-app/.
- Run npm test, npm run lint, npm run typecheck and npm run build for code changes.
- Keep credentials, the .data directory and environment files out of commits.
- Authorize resources on the server. UI guards are not access control.
- Never report a save, test result or release gate as passed without evidence.
- Keep documentation specific to the implementation and describe unfinished features plainly.
