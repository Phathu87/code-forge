# CodeForge Brand System 1.0

Product: **CodeForge**. Owner/author recorded by the project: Phathutshedzo Rakhunwana. Product version: 0.1.0 development preview. This extraction preserves the existing dark-first application; it is not a new identity or a release approval.

Primary positioning: **Learn to build. Not prompt.** Product philosophy: **You write the code. We help you understand it.** Journey: **Learn. Build. Debug. Prove. Grow.** Use one where it helps, not all as repeated decoration. Code Coach is the assistant label; do not describe it as an autonomous builder.

The approved design origin is the exported Base44 frontend, as identified by the owner. Production has no Base44 runtime dependency. The original Programming Language Toggle App is preserved as project history and mission origin, never the current product name. The maintained authority is this repository's extracted tokens and components.

The existing blue rounded tile with Lucide Code2 paths is the mark. `src/assets/brand/mark.svg` is its extracted vector master; `BrandMark.jsx` consumes its public copy. The previous mint-on-dark favicon was inconsistent and is replaced by this mark. New maskable, monochrome, notification and raster variants are explicitly derived, not separately approved historical artwork. Ordinary text is the wordmark; no bespoke wordmark artwork or proprietary font is asserted.

Use a single accessible CodeForge name for a logo link. The mark is decorative beside visible CodeForge text. Standalone marks use BrandMark with decorative=false. Keep clear space of at least one quarter of the mark width; never stretch it or place the full wordmark in a launcher tile. The maskable mark fits inside the central safe area.

Use clear, practical and respectful language. Report infrastructure failure separately from learner test failure. Neutral integrity labels include Additional verification required and This submission requires review. Never use a verification shield for an example, ordinary completion, XP or a self-declared skill. Certificates, employer verification and public evidence remain disabled until their release gates pass.

Dark theme is the actual implementation. Inter and JetBrains Mono appear in the CSS stacks but are not downloaded or bundled; system fallbacks render where they are unavailable. No font redistribution rights are claimed. The inactive theme switch was removed rather than advertising a functioning light theme.

Brand changes require an intentional reviewed revision. Preserve accessibility, security and truthful status over decorative parity. See [design system](design-system.md), [assets](brand-assets.md), [ownership](brand-ownership.md) and [closeout](brand-closeout.md).
